> **A simple, user-friendly Android calculator** built with **Kotlin** and modern **Material Design** interface for basic arithmetic operations 📱✨

---

## ✨ Features

- **➕ Basic Arithmetic** — Addition, subtraction, multiplication, and division operations
- **🔢 Decimal Support** — Handle decimal numbers and clear entries easily  
- **🎨 Modern UI** — Clean Material Design layout with responsive buttons and fonts
- **📜 History Log** — Maintains calculation history for review (swipe or view history screen)
- **⚠️ Error Handling** — Gracefully handles invalid operations (e.g., divide by zero)
- **🪶 Lightweight** — No ads or unnecessary permissions; runs smoothly on most Android devices

## 🚀 Installation & Running

### 1️⃣ Clone the Repository
```bash
git clone https://github.com/dkyYadav/Calculator.git
cd Calculator
```

### 2️⃣ Open in Android Studio
- 📂 Launch **Android Studio**
- 🔍 Choose **Open an Existing Project**
- 📁 Select the cloned directory

### 3️⃣ Build the Project
- 🔄 Android Studio should **sync and build** automatically
- 📦 Install any required SDK components if prompted

### 4️⃣ Run on Device/Emulator
- 🔌 **Physical Device:** Connect via USB (enable USB debugging)
- 📲 **Emulator:** Start an Android emulator in Android Studio
- ▶️ Click the **Run** button to install and launch the app

## 🎯 Key Operations

| Operation | Symbol | Description |
|-----------|---------|-------------|
| ➕ Addition | `+` | Add two or more numbers |
| ➖ Subtraction | `-` | Subtract numbers |
| ✖️ Multiplication | `×` | Multiply numbers |
| ➗ Division | `÷` | Divide numbers (with zero-division protection) |
| 🔢 Decimal | `.` | Support for decimal calculations |
| 🗑️ Clear | `C` | Clear current entry or all entries |
